# 客观题单次提交

插件包：`@hydrooj/objective-once`。Docker 默认加载；本地部署请将
`packages/objective-once` 的绝对路径加入 Hydro 的 `addon.json`，重启服务。
使用自定义 `HYDRO_ADDONS` 时需加入 `/opt/hydro-addons/objective-once`。
所有服务进程都应加载此插件。UI-NEXT 会自动发现插件的比赛设置界面。

创建或编辑比赛时勾选 **客观题仅允许提交一次**。默认关闭，开赛后不可改变。
所有比赛赛制均适用，普通练习、作业和编程题不受影响。

限制单位为“域、比赛、题目、参赛者”，团队比赛为整队共享一次。
一道 Hydro 客观题中的选择题和填空题组成整份答卷。提交前确认；未答完时
列出未作答的小题，允许返回继续作答或确认提交，未作答的小题计零分。
已有提交的页面恢复实际提交内容并锁定输入，草稿不会覆盖已提交的答案。
成绩和评测详情是否可见继续遵循比赛赛制。

服务端在创建记录前检查策略，并在提交记录上使用数据库唯一索引，防止并发、
换设备、直接请求或队友重复提交。记录成功创建即用掉机会；后续排队或评测失败
可由管理员重评原记录。请求未创建记录时不消耗机会，响应丢失后可刷新找回记录。
取消成绩或重评不会恢复机会；删除原提交记录属于管理员操作，会释放对应限制。
比赛删除后的关联记录仍保留唯一标记，不会影响其他比赛。

插件为核心增加三个通用扩展事件：`contest/edit-settings`、`record/before-add`、
`record/insert-error`；核心不保存插件专属比赛设置。
