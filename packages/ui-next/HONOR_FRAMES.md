# 荣誉头像框

## 入口与操作

- 系统管理员：Topbar 个人下拉菜单 → 头像框管理。移动端个人菜单也有入口，系统管理 dashboard 不再放置入口。
- 管理列表显示已发布（绿色）和已停用（红色）的头像框，24 个/页；按名称搜索。点击名称可直接编辑，保存按钮提交，Esc 取消。
- 点击状态按钮，经过确认弹窗后发布或停用。卡片悬停时右上角显示查看、删除按钮；键盘聚焦、触屏也可访问。删除需再次确认，会移除所有用户的拥有资格及当前佩戴，不影响其他头像框。
- 顶部“上传头像框”进入独立页面；“授予头像框”打开弹窗：名称搜索、单选头像框，用户名/UID 搜索、多选用户，最多 50 人/次。搜索包含已停用项并标明状态，仅已发布头像框可选择授予。
- 拥有者列表：25 人/页，可搜索、单独操作或勾选本页用户批量操作。
  - 启用（佩戴）：替换该用户当前佩戴的头像框。
  - 停用（取消佩戴）：保留拥有资格，只在当前佩戴的是这个头像框时取消，不影响其他头像框。
  - 收回：移除拥有资格，同时取消对这个头像框的佩戴。
- 用户：个人设置 → 荣誉头像框，独立页面 `/home/honor-frames`，12 个/页，可佩戴/取消佩戴已发布的头像框。
- 个人主页：个人简介、已通过题目之后新增“拥有的头像框”，所有访问者可查看，12 个/页，包括已停用但仍拥有的头像框。

## 素材规范（像素）

一个名称对应圆角方形和圆形两份素材，两份必须同时上传，支持拖拽或点击选择。

| 项目 | 圆角方形素材 | 圆形素材 |
| --- | --- | --- |
| 完整画布 | 512 × 512px | 512 × 512px |
| 中间透明头像区域 | 384 × 384px | 直径 384px |
| 定位 | 左上角 (64, 64) | 圆心 (256, 256) |
| 圆角半径 | 64px | 192px |
| 四周装饰空间 | 各 64px | 各 64px |

“留白”指透明，不是白色背景。中心区域不应放置装饰，以免遮挡头像。
服务端按圆形/圆角方形分别检查中心，边缘保留 2px 抗锯齿容差，允许 alpha ≤ 8/255 的近透明导出残留。中心出现更明显的装饰时允许上传并提示检查预览，不作为格式错误拒绝。图片必须同时包含透明与可见像素，不能完全不透明或全透明。
每份素材支持透明 PNG/WebP，最大 2MiB；WebP 在浏览器转换为静态 PNG。
服务端独立检查真实格式、尺寸、CRC、PNG 数据块、透明区域，并重新编码去除附加信息；不接收 SVG/HTML。

个人主页的大头像使用圆形素材，其他默认使用圆角方形素材。所有尺寸等比缩放：
若头像内容宽为 `S`，外框宽为 `4S/3`，每边预留 `S/6`，圆角方形内容圆角为 `S/6`。
例如内容 96px → 外框 128px、每边 16px；内容 36px → 外框 48px、每边 6px。
未佩戴、图片加载中、图片失败时保持相同预留空间。域头像不受影响。

旧单素材头像框仍可显示、管理、授予、撤回，双形状均回退原素材；不会自动生成缺失形状。
新上传严格使用双素材规范。旧素材的图案本身无法保证适合两种形状，建议后续重新制作符合规范的版本。

## 全局数据与安全

- `honor.frame` 保存名称、发布状态、创建信息；新素材有 `artworkVersion: 2`。
- 图片路径为 `honor-frame/{id}-square.png` 和 `honor-frame/{id}-circle.png`，旧文件路径保留。
- 全局 `user.honorFrameIds` 是拥有资格，`user.honorFrameId` 是当前佩戴选择，不写入 `domain.user`。
- 所有管理页面、搜索、上传、写入接口都要求系统权限 `PRIV_EDIT_SYSTEM`，仅有域管理员权限不够。
- 普通用户佩戴使用会话 UID；管理批量操作校验正整数 UID、人数上限、用户存在及拥有资格。
- 撤回资格和取消佩戴为同一用户文档的原子更新；启用操作在写入过滤条件中再次验证资格。
- 批量操作是逐文档原子的，不是跨用户事务；并发资格变化导致部分未匹配时返回实际匹配人数并提示刷新重试。
- 发布状态和名称分别更新，避免重命名覆盖并发发布结果。管理写入均记录操作日志。
- 删除先标记停用及删除中，再清理全局用户资格、素材和目录；失败可重试，删除中的素材不能重新发布。并发授予/佩戴会在写入后检查删除状态并清理失效引用。文件使用现有存储服务的延迟清理机制。
- 搜索正则经过转义、限制长度；用户搜索最多返回 50 条，只返回选择所需 UID、用户名，不暴露邮箱等账户数据。
- 从未授予的停用素材仅系统管理员可预览；已经授予的素材即使停用，也可在公开收藏展示，但不能继续佩戴/授予。
- 全局停用保留资格及佩戴选择，重新发布后恢复显示。若要清除特定用户选择，使用拥有者页面的取消佩戴。
- 变更后清理跨域用户缓存并通知其他服务进程。已打开页面需刷新获取管理员的最新更改。
- 页面跳转使用现有域路由生成器；图片资源是全局根路径，不因域切换改变。

无须升级 MongoDB 或手工迁移旧数据。新拥有者查询索引随启动建立；需要同步构建、重启后端和 ui-next。

## 接口

下列页面及接口支持当前部署的 `/d/{domainId}` 路由前缀，但操作同一份全局数据。

| 地址 | 用途 |
| --- | --- |
| `GET /manage/honor-frames?page=1&q=名称` | 管理列表 |
| `GET /manage/honor-frames/upload` | 双素材上传页面 |
| `GET /manage/honor-frames/search?kind=frames或users&q=关键词` | 授予弹窗搜索 |
| `GET /manage/honor-frames/{id}/owners?page=1&q=关键词` | 拥有者管理列表 |
| `POST /manage/honor-frames`，`operation=upload` | 上传 `name`、`square`、`circle` |
| 同上，`operation=rename` | 修改 `id` 对应 `name` |
| 同上，`operation=status` | 修改 `id` 对应 `active` |
| 同上，`operation=delete` | 删除 `id`，同时收回所有用户的该头像框 |
| 同上，`operation=owners` | `id`、`uids`，`action=grant/revoke/equip/unequip` |
| `GET /home/honor-frames` | 用户独立设置页；`noTemplate=true` 获取分页数据 |
| `POST /home/honor-frames` | 佩戴 `id`，空串取消佩戴 |
| `GET /user/{uid}/honor-frames?page=1` | 公开拥有的头像框 |
| `GET /honor-frame/{id}/{square或circle}.png` | 对应形状图片 |
| `GET /honor-frame/{id}.png` | 兼容旧图片地址，新素材回退方形 |

## 默认代码模板

个人设置 → 偏好 → 默认代码模板。非空字符串优先于系统模板，保留原有缩进和换行；清空或只含空白时回退所选语言的系统模板。
在线编辑器首次打开无草稿时、点击“加载模板”时，以及独立提交页面均使用此规则。
已有草稿、代码回放恢复内容和已提交代码优先，不因偏好变化或切换语言被自动覆盖。

## 测试重点

- 双素材尺寸和中心透明度、旧素材兼容、形状选择和固定占位。
- 管理权限、未获授拒绝佩戴、批量人数边界、收回/佩戴竞态。
- 主域/子域链接、全局公开序列化、拥有者分页、搜索转义与公开字段限制。
- 上传失败保留输入和清理存储，重复点击锁定，异步搜索及多用户选择。
- 个人模板优先、空白回退和草稿优先。

对应测试在 `packages/hydrooj/tests/honor-frame*.spec.ts`、`packages/ui-next/tests/honor-frame.spec.ts` 和 `code-templates.spec.ts`。
