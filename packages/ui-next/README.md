# ui-next 开发服务

在仓库根目录运行：

```sh
yarn debug --port=2333 --watch
```

浏览器访问启动日志 `Server listening at` 对应的 HTTP 地址。HTTP 端口被占用时会明确报错并清理当前启动失败的实例，不会自动换 HTTP 端口，以免浏览器误访问旧实例。

Vite 热更新使用每个开发实例独立分配的空闲端口，不再固定占用 3010；页面会自动获得对应端口。热更新端口在实例退出后释放。
如果远程开发或反向代理需要固定热更新端口，可以显式配置：

```sh
HYDRO_UI_NEXT_HMR_PORT=3011 yarn debug --port=2333 --watch
```

正常退出会先停止事件轮询、停止接收后台任务并等待已开始的任务结束，再关闭数据库。再次按 Ctrl+C 仍可强制退出。
